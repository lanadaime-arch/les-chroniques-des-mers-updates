# Les Chroniques des Mers — jeu web public

**Version jouable : 1.2.1 (code 12201).**

🎮 **Jouer :** https://lanadaime-arch.github.io/les-chroniques-des-mers-updates/

Cette adresse sert le jeu en français, gratuit et jouable dans un navigateur moderne. Le même site est chargé par les **applications Windows et Android** en cours de test. Sur iPhone, Safari permet d'ajouter le jeu à l'écran d'accueil.

## Mise à jour
Les mises à jour **web** sont publiées ici depuis le projet de développement privé après validation. Le service worker change de cache à chaque publication et conserve les ressources nécessaires à la consultation hors ligne après un premier chargement, selon les capacités du navigateur. Aucun nouveau binaire Windows/Android n'est nécessaire pour une mise à jour web ; un changement des applications natives demande un nouvel installateur.

## Sauvegardes
Les données des personnages sont enregistrées **localement** dans le navigateur ou l'application. Il n'y a **aucune synchronisation automatique** entre Netlify, GitHub Pages, Android, Windows et iPhone. Utiliser les boutons **Exporter** et **Importer** avant de changer d'appareil, de navigateur ou de site.
